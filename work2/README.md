# 注意实验室 · Attention Lab

工程心理学 作业二：构建一个「注意实验室」——复现 + 改进

纯前端（HTML + CSS + JavaScript，无框架、无构建、无 CDN）实现的三个经典注意实验，每个实验都在经典范式之外加入一个**新的改进条件**，并在同一网页内完成数据收集、效应量计算与结果可视化。

| 序号 | 实验 | 周次 | 经典范式 | 改进条件 |
| --- | --- | --- | --- | --- |
| 01 | 驾驶注意瞬脱 | W5 选择性注意 | Raymond, Shapiro & Arnell (1992) | 事故前 400 ms 全屏 HUD 警报线索 |
| 02 | 座舱负启动 | W6 搜索与并行加工 | Tipper (1985)；Eriksen & Eriksen (1974) | 干扰仪表弱高亮（浅灰边框） |
| 03 | 比例判断 | W7 显示设计 | Cleveland & McGill (1984)；Hollands & Dyre (2000) | 刻度 × 格式交叉（比例避开刻度值） |

三个实验均为被试内设计，全部流程（知情同意 → 匿名编号 → 指导语 → 练习 → 正式试次 → 结束页）在同一页面内完成，无刷新跳转。

## 四、实验 1 · 驾驶注意瞬脱（W5）

### 4.1 背景与出处

注意瞬脱（attentional blink）：在快速序列呈现中，正确识别第一个目标（T1）后，约 200–500 ms 内出现的第二个目标（T2）识别正确率显著下降，形成 U 形或“先降后升”的曲线。

- 出处：Raymond, J. E., Shapiro, K. L., & Arnell, K. M. (1992). *Temporary suppression of visual processing in an RSVP task: An attentional blink?* JEP:HPP.
- 驾驶情境改编参照：Horrey, W. J., et al. (2006) 关于车内任务与视觉注意分配的研究；以及 Senders (1964) 的 SEEV 注意采样框架。

### 4.2 变量设计（2 × 4 被试内）

| 因素 | 水平 | 说明 |
| --- | --- | --- |
| 预警条件（block） | `baseline` / `warning` | 基线：事故突然出现；改进：事故前 400 ms 全画面亮起醒目的橙色 HUD 警报（脉冲边框 + 顶部警示条 + 四角括号） |
| Lag（block 内随机） | 100 / 300 / 500 / 700 ms | T1 出现到 T2 出现的时间间隔 |

- **因变量 1（核心）**：T2 条件正确率 = 仅在 T1 答对的试次中，行人上衣颜色判断正确的比例。
- **因变量 2**：T1 识别正确率（事故类型四选一）。
- **因变量 3**：T1 反应时（事故出现 → 按下转向键，`performance.now()`）。

### 4.3 刺激

- 场景：SVG 第一人称城市道路，天空/路面/车道虚线/路灯/远山，`requestAnimationFrame` 驱动透视动画持续流动。
- T1（事故）：紧急刹车、路面落物、电动车横穿、前车变道，共 4 种，呈现 550 ms；采用拟真 SVG 绘制（车身车窗、刹车灯/转向灯、车轮、投影等），保证被试能看清并做出转向反应。
- T2（行人）：红 / 蓝 / 黑 / 白 4 种上衣颜色，呈现 100 ms；**仅在被试按空格完成转向后才出现**（按空格时刻起延迟 Lag ms），若 2.2 s 内未按空格则 T2 不出现、直接进入作答；一半出现在画面左侧、一半右侧。行人采用拟真 SVG（头、头发、躯干、手臂、腿、鞋）。
- 填充试次：只出现 T1、不出现 T2（2 试次/block），避免被试形成“总有第二个目标”的预期。
- 场景为白天：蓝天、明亮的沥青路面、白色车道线与路灯；事故发生后按空格会播放一次“向左避让”的镜头动画（横向偏移 + 轻微侧倾）。
- **视觉风格**：整体采用玻璃拟态（glassmorphism）的车载 HUD / 航电显示风格——深色通透背景、半透明磨砂顶栏、薄高光边框、微发光边缘与浅色发光文字，问题与引导面板均为半透明毛玻璃卡片。

### 4.4 单试次流程

1. 注视点 500 ms
2. 道路画面流动 **1.0–3.4 s（区间内随机）**，事故出现时刻不可预期
3. （warning 条件）全画面橙色 HUD 警报 400 ms（脉冲边框 + 顶部警示条 + 四角括号）
4. T1 事故出现，停留 550 ms；被试按 **空格** 做转向反应，画面播放避让动画
5. **按空格后**，按 Lag 延迟呈现 T2 行人 100 ms（未按空格则跳过）
6. 作答界面（事故后最长等待 2.2 s 未按空格也会进入作答）
7. 问题 1：刚才的事故类型是？（4 选 1）
8. 问题 2：行人的衣服颜色是？（4 种颜色 + “未出现行人”共 5 选 1）
9. 反馈 500 ms → 下一试次

### 4.5 试次与平衡

- 练习：4 试次（只使用 Lag 300 / 500，交替出现有/无预警，不计入数据、给出正误反馈）
- 正式：2 个 block × 10 试次 = **20 试次**（分 2 轮，每轮 10 个）
  - 每 block：4 个 Lag × 2 试次 = 8，加 2 个填充试次
  - 每个 Lag 条件在两个 block 合计 4 试次（每个预警条件各 2 次）
- block 顺序按被试编号哈希平衡：一半被试 baseline → warning，另一半相反（`U.hash(pid) % 2`），不需要人工分配。
- 两 block 之间 15 s 休息页。

### 4.6 数据字段

```
participant_id, trial_num, block_type, lag_ms,
t1_type, t1_response, t1_correct, t1_rt,
t2_present, t2_color, t2_side, t2_response, t2_correct
```

## 五、实验 2 · 座舱负启动（W6）

### 5.1 背景与出处

负启动（negative priming）：启动显示中被忽略的干扰项，在探测显示中变成目标时，反应时反而变长——反映了对干扰项的主动抑制及其后效。

- 出处：Tipper, S. P. (1985). *The negative priming effect: Inhibitory priming by ignored objects.* QJEP.
- 干扰效应背景：Eriksen, B. A., & Eriksen, C. W. (1974). *Effects of noise letters upon the identification of a target letter in a nonsearch task.* P&P.

### 5.2 变量设计（2 × 3 被试内）

| 因素 | 水平 | 说明 |
| --- | --- | --- |
| 显示条件（block） | `baseline` / `highlight` | 基线：仅目标红框；改进：非目标仪表加极淡浅灰边框 |
| 试次类型（block 内随机） | `control` / `positive` / `negative` | 控制：启动与探测无关联；正启动：探测目标 = 启动目标；负启动：探测目标 = 启动干扰项 |

- **因变量 1（核心）**：探测任务反应时（仅统计启动与探测都正确的试次）。
- **因变量 2**：探测任务正确率。
- **效应量**：负启动量 = RT(negative) − RT(control)；正启动量 = RT(positive) − RT(control)。

### 5.3 界面

- 整体采用**飞机座舱仪表盘**风格：顶部为**前窗视图**（天空渐变、云层、远山、地平线、跑道与跑道灯），下方为仪表区。
- 6 个圆形仪表 2 行 × 3 列（高度、速度、航向、燃油、液压、温度），采用拟真 SVG：
  - 主刻度数字 0 / 25 / 50 / 75 / 100 沿弧线分布，次刻度每格细分；
  - 高值区（75–100）有**红色警示弧**，顶部有红色中线标记作为参照；
  - 表圈径向渐变光泽，指针带反向短尾。
- 指针位于中间刻度以下/以上即为“偏低/偏高”。
- 目标仪表：红色边框；干扰仪表：灰色边框；`highlight` 条件下干扰仪表带浅灰半透明边框。
- 反应键：**F = 偏低**，**J = 偏高**（同时提供屏幕按钮，支持触屏）。超时 3000 ms 记为错误。

### 5.4 单试次流程

1. 注视点 500 ms
2. 启动界面（1 目标 + 5 干扰）→ 被试按 F/J → 记录启动 RT 与正误
3. 空白 500 ms（SOA）
4. 探测界面（1 目标 + 5 干扰）→ 被试按 F/J → 记录探测 RT 与正误
5. 正误反馈 500 ms → 下一试次

### 5.5 试次与平衡

- 练习：6 试次（3 种试次类型各 2 次，基线显示，不计入数据）
- 正式：2 个 block × 18 试次 = **36 试次**，每种试次类型 6 次（两段合计 12 次）
- 目标仪表的位置与类型在试次生成时打乱，保证各仪表作为目标/干扰的频次接近一致
- block 顺序按被试编号哈希平衡；两 block 之间 15 s 休息页

### 5.6 数据字段

```
participant_id, trial_num, block_type, trial_type,
prime_target, prime_side, prime_rt, prime_correct,
probe_target, probe_side, probe_rt, probe_correct
```

## 六、实验 3 · 比例判断（W7）

### 6.1 背景与出处

Cleveland & McGill (1984) 的图形知觉层级：位置/长度（条形图）> 角度/面积（饼图）。Hollands & Dyre (2000) 进一步指出，饼图缺少可对齐的外部参照，导致估计向 50% 回归。

- 出处：Cleveland, W. S., & McGill, R. (1984). *Graphical perception.* JASA.
- Hollands, J. G., & Dyre, B. P. (2000). *Bias in proportion judgments: The cyclical power model.* Psychological Review.

### 6.2 变量设计（3 × 2 被试内）

| 因素 | 水平 | 说明 |
| --- | --- | --- |
| 显示格式（block） | `pie` / `bar` / `area` | 饼图 / 条形图 / 面积图（嵌套正方形） |
| 刻度条件（段内随机交叉） | `ticks` / `plain` | 有刻度 / 无刻度；同一比例分别在有、无刻度下各出现一次 |
| 真实比例（段内随机抽取） | 12%–89%，刻意避开 25/50/75 与 5 的倍数 | 每段抽 5 个比例 × 2 刻度条件 = 10 试次 |

- **因变量 1（核心）**：绝对误差 = |估计值 − 真实比例|（百分点）
- **因变量 2**：方向偏差 = 估计值 − 真实比例（检验向 50% 回归）
- **因变量 3**：判断反应时

### 6.3 刺激与操作

- 饼图：高亮扇区为橙色，其余为浅灰底；`ticks` 条件外圈每 5% 一个小刻度、25/50/75 三条主刻度并标注数字。
- 条形图：共同基线上的长度编码；`ticks` 条件上方标出 0–100% 刻度（25% 为主刻度）。
- 面积图：嵌套正方形，内方**面积** = 整体的 prop%；`ticks` 条件用虚线方框标出面积 25/50/75 的参照。
- **有刻度 ≠ 按刻度出题**：真实比例刻意避开 25/50/75 等刻度值（且不是 5 的倍数），被试不能直接“读刻度”作答。
- 操作：拖动滑块（0–100）、按 ←/→ 微调（Shift 加速）；数字输入框在每试次开始时自动聚焦并全选，**无需先点击即可直接敲键盘输入数字**（首字符替换默认值，后续追加），输入值**限制在 0–100**（超过 100 自动钳位为 100）；按 **Enter** 或点「确认」提交。
- 试次间有 500 ms 注视点，超时 20 s 记为未作答。

### 6.4 试次与平衡

- 练习：6 试次（饼图 / 条形图 / 面积图 × 有 / 无刻度 各 1 次，显示正确答案，不计入数据）
- 正式：3 个 block × 10 试次 = **30 试次**
  - 每段固定一种显示格式，抽 5 个比例，每个比例在有、无刻度下各出现 1 次，段内随机交叉
- 3 个 block（格式）的顺序采用 **6 种排列的拉丁方**，按 `U.hash(pid) % 6` 分配，抵消顺序与练习效应
- block 之间 10 s 休息页

### 6.5 数据字段

```
participant_id, trial_num, block_type, trial_type, display_format,
ticks, tick_condition, true_proportion, estimate, abs_error, signed_error, rt
```

## 七、收数前的理论预测

> 本节在收集任何数据之前写定并提交，用于事后对照，不做事后修改。

### 7.1 实验 1（注意瞬脱 + 预警）

- **复现预测**：基线条件下 T2 条件正确率呈 U 形，Lag 300 ms 最低、Lag 700 ms 回升，瞬脱幅度（Lag700 − Lag300）显著大于 0。
- **改进预测**：预警线索在事故前 400 ms 把注意提前分配到事故位置（符合 SEEV 的期望价值与注意资源预分配），使 T1 占用注意资源的“峰值”被提前消化，因此 warning 条件的瞬脱幅度应**小于** baseline。
- **次要预测**：预警可能提高 T1 正确率，但同时可能带来“预警依赖”，对 Lag 100 的 T2 影响不大（资源竞争尚未解除）。

### 7.2 实验 2（负启动 + 弱高亮）

- **复现预测**：`negative` 条件的探测 RT 显著长于 `control`（负启动量 > 0）；`positive` 条件短于 `control`（正启动量 < 0）。
- **改进预测**：给干扰仪表加极淡边框会降低“必须主动抑制”的程度（抑制强度下降），因此 `highlight` 条件下的负启动量应**小于** baseline。
- **次要预测**：弱高亮同时可能略微提高整体正确率，因为干扰项被明确标记为“可安全忽略”。

### 7.3 实验 3（比例判断 × 刻度）

- **复现预测**：绝对误差 `bar` < `pie` ≈ `area`；无刻度条件存在向 50% 的回归（低于 50% 的比例被高估、高于 50% 的被低估，即 signed_error 与 (50 − 真实值) 同向）。
- **改进预测**：同一格式下，`ticks` 的绝对误差显著小于 `plain`（外部参照把角度/面积判断转化为可对齐的位置判断）；由于比例刻意不落在刻度上，刻度只能减小误差而不能“直接给出答案”，改善幅度应温和而非完全消除误差。

## 九、结果与讨论

### 9.1 计算方式

| 指标 | 公式 |
| --- | --- |
| 实验1 T2 条件正确率 | 在 `t1_correct = 1` 且 `t2_present = 1` 的试次中，`t2_correct = 1` 的比例 |
| 实验1 瞬脱幅度 | Acc(Lag 700) − Acc(Lag 300) |
| 实验1 改进效果 | 瞬脱幅度(baseline) − 瞬脱幅度(warning) |
| 实验2 负启动量 | RT(negative) − RT(control)，仅用 `prime_correct = 1 且 probe_correct = 1` 的试次 |
| 实验2 改进效果 | 负启动量(baseline) − 负启动量(highlight) |
| 实验3 绝对误差 | mean(|estimate − true_proportion|) |
| 实验3 方向偏差 | mean(estimate − true_proportion) |

## 十一、已知限制

- 反应时为键盘/滑块输入延迟所限，精度在 ±10 ms 量级；未做显示器刷新率校准。
- 计时依赖浏览器主线程，切换到其他标签页会暂停 `requestAnimationFrame` 动画（不影响已记录的试次）。
- `localStorage` 为浏览器本地存储，清理站点数据会丢失未导出的记录，建议每位被试完成后立即导出 CSV。
