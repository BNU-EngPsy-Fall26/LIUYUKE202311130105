# 自动驾驶目标识别 · 信号检测论（SDT）交互式实验

自选信号检测论应用场景，使用 HTML + CSS + JavaScript（Canvas）实现的可交互检测游戏。
玩家扮演自动驾驶汽车的**感知系统**，在夜间行车画面短暂闪现后判断前方道路**是否存在行人 / 障碍物**，游戏结束自动给出完整的信号检测论计算结果与概念可视化。

## 一、运行方法

纯前端项目，**无需安装任何依赖、无需后端**。
**点击链接直接在线试玩：** https://bnu-engpsy-fall26.github.io/LIUYUKE202311130105/

## 三、场景与参数定义

- **信号 S**：前方道路上**确实出现**行人 / 路障（正确反应 = 刹车）。
- **噪音 N**：前方道路**空旷无异常**，只有夜雾与路侧护栏、灌木等干扰物（正确反应 = 继续行驶）。
- **先验概率 P(S)**：每局中信号试次的占比，可在 0.10–0.60 间调节（默认 0.30）。

|  | 报告「刹车」 | 报告「继续」 |
| --- | --- | --- |
| **实际有障碍（信号 S）** | 击中 Hit (H)：正确刹车 | 漏报 Miss (M)：未刹车，危险 |
| **实际无障碍（噪音 N）** | 虚警 False Alarm (FA)：误刹车 | 正确拒斥 CR：正确继续 |

## 四、玩法

1. 在开始页调节参数：难度 **d′**（0.5–3.0，越大目标越清晰、夜雾越淡）、先验概率 **P(S)**、每局试次数（20–60）、刺激呈现时长（500–3000 ms）。
2. 每个试次的流程：注视提示 → 路况画面**限时呈现** → 画面被噪点掩蔽消失 → 在 **3 秒内凭记忆作答**（超时自动记为「继续行驶」）→ 看到反馈。
3. 作答方式：点击按钮，或键盘 **J / ←** = 继续行驶、**K / →** = 刹车。
4. 一局结束后查看完整结果。

## 五、SDT 指标与计算

先计数 H / M / FA / CR（信号试次数 nS = H+M，噪音试次数 nN = FA+CR），再计算：

- 击中率：P(Hit) = (H + 0.5) / (nS + 1)
- 虚警率：P(FA) = (FA + 0.5) / (nN + 1)
- 辨别力：**d′ = z(P(Hit)) − z(P(FA))**
- 判断标准：**c = −[ z(P(Hit)) + z(P(FA)) ] / 2**
- 反应偏向（似然比）：β = exp( [ z(FA)² − z(H)² ] / 2 )
- 准确率：(H + CR) / N
- ROC 曲线下面积：Az = Φ(d′ / √2)

> 注：P(Hit)、P(FA) 采用 **log-linear 校正（每格计数 +0.5）**，避免出现 0 或 1 时 z 分数为 ±∞。
> z 为标准正态分位数函数（Acklam 近似算法），Φ 为标准正态累积分布函数。

判读：c < 0（β < 1）标准偏宽松，倾向多刹车、虚警多而漏报少；c > 0（β > 1）标准偏保守，漏报风险增加。
